How to create the token
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Token name: anything, e.g. “Case collector”. Expiration: your choice; paste a new token here when it expires.
  3. Repository access: “Only select repositories”, then pick your library repo only.
  4. Permissions → Repository permissions → Contents: “Read and write”. Leave everything else as is.
  5. Click Generate token, copy it, and paste it above.
